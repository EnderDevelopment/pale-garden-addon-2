# PaleGardenAddon

PaleGardenAddon is a Minecraft Bedrock Edition addon designed to recreate features from versions 1.21.30 through 1.21.52. It includes the Pale Garden biome, Pale Oak trees, Creaking mob, Creaking Heart, Eyeblossoms, resin blocks, bundles, and other compatible blocks, items, mobs, and gameplay features. This addon is optimized for mobile devices and is compatible with Bedrock 1.21.52.

## Install

1. Download the `.mcaddon` file from the [GitHub releases page](https://github.com/EnderDevelopment/PaleGardenAddon/releases).
2. Open the Minecraft Bedrock Edition game on your mobile device.
3. Tap the three dots in the top right corner to open the settings menu.
4. Select "Add-ons" from the settings menu.
5. Tap the "+" button in the top right corner.
6. Select the `.mcaddon` file you downloaded.
7. Tap "Open" to install the addon.
8. Enable the addon by toggling the switch next to its name.

## Use

1. Start a new world or open an existing one.
2. Explore the world to find the Pale Garden biome.
3. Interact with Pale Oak trees, Creaking mobs, Creaking Hearts, and Eyeblossoms.
4. Use resin blocks and bundles to enhance your gameplay experience.
